# Prove host 1Password credential brokering

Type: research
Status: open
Blocked by: 02, 07

## Question

Can mntwork securely broker the host macOS 1Password SSH agent for Git/SSH authentication and commit signing, plus explicitly selected non-key secrets, into each supported Sandbox Environment without copying private keys or granting broad vault access, and how should consent, biometric prompts, revocation, redaction, and runtime-specific socket transport behave?
