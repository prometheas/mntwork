# Define the Capability Catalog and conformance matrix

Type: prototype
Status: open
Blocked by: 02

## Question

What versioned, machine-readable schema should record evidence-backed Runtime Driver capability claims across driver/backend versions, host and runtime-host combinations, and configuration conditions; how should conformance tests and official-source evidence maintain those claims over time; and how should one source generate a human-readable matrix without replacing live Capability Reports or treating unknown combinations as unsupported?
