# Prove macOS runtime isolation strategies

Type: research
Status: open
Blocked by: 02

## Question

On macOS Apple Silicon, can Docker Sandboxes, nested rootless Podman, and Apple's `container` CLI provide the required microVM-grade host isolation, multiple absolute-path mounts, persistent Workspace lifecycle, networking, shared artifact reuse, and an internal Docker or Podman workload engine with acceptable startup and steady-state performance?
