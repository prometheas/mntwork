# Serialize shared repository authority across Workspaces

Different Workspace Definitions may reference Worktree Contexts sharing writable common refs, configuration, hooks, objects, and worktree administration, including through distinct paths that expose the same live directory object. One Host Scope Lease Manager therefore compares candidates with every active or reserved lease and atomically reserves the complete live repository-authority equivalence set before preparation; it retains that Repository Lease until Sandbox absence is verified, while weak or incomparable active evidence fails closed. Explicit per-Workspace shared-repository policy may permit overlap across the whole set, but force flags never bypass it, trading unrestricted parallel starts for an honest isolation boundary while multiple worktrees inside one Workspace remain supported.
